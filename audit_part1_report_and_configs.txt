RELEASE-READINESS AUDIT REPORT: GOOGLE PLAY STORE & APPLE APP STORE

--------------------------------------------------------------------------------
1. LEGAL AND STORE-POLICY ISSUES
--------------------------------------------------------------------------------

[BLOCKER - Apple App Store] Restricted Kernel Entitlements
- Location: ios/FinanceFlow/FinanceFlow.entitlements:L5-L8, app.json:L60-L66
- Issue: "com.apple.developer.kernel.increased-memory-limit" and 
  "com.apple.developer.kernel.extended-virtual-addressing" are restricted capabilities.
  Submitting without explicit Apple Developer account entitlement grant causes
  immediate ITMS-90046 code signing rejection on App Store Connect.
- Fix: Set "enableEntitlements: false" in app.json llama.rn config, and remove the
  keys from FinanceFlow.entitlements unless Apple has granted formal documentation.

[BLOCKER - Google Play & Apple] Missing Hosted Privacy Policy URL Link
- Location: app/about.js:L110-L121, app/onboarding.js:L308-L310
- Issue: Privacy Policy is only in-app text ("100% On-Device SQLite"). Both stores
  (Apple Guideline 5.1.1(i) and Google Play User Data Policy) require a publicly
  accessible, web-hosted URL in store metadata and linked inside the app.
- Fix: Host privacy policy on web domain; link via Linking.openURL in about.js
  and make "Privacy Policy" clickable in onboarding.js.

[BLOCKER - Google Play Store] Suppressed Android Camera & Post-Notification Permissions
- Location: app.json:L33-L36, android/app/src/main/AndroidManifest.xml:L2-L5
- Issue: app.json explicitly restricts permissions to ["INTERNET", "VIBRATE"],
  omitting CAMERA and POST_NOTIFICATIONS. On Android:
  1. launchCameraAsync() crashes or fails permission for receipt photo taking.
  2. Android 13+ (API 33+) local notifications fail silently.
- Fix: Add CAMERA and POST_NOTIFICATIONS to app.json and AndroidManifest.xml.

[BLOCKER - Google Play Store] Release Build Uses Debug Keystore
- Location: android/app/build.gradle:L109-L113
- Issue: release buildType configures "signingConfig signingConfigs.debug".
  Google Play Console rejects AAB/APK signed with debug certificate.
- Fix: Configure production upload keystore in gradle.properties and build.gradle.

[HIGH - Apple App Store] App Group Identifier Configuration
- Location: ios/FinanceFlow/FinanceFlow.entitlements, ios/FinanceFlowWidget/FinanceFlowWidget.entitlements
- Issue: "group.com.financeflow.app" must be created and assigned to both App IDs
  in Apple Developer Portal, otherwise Xcode archive validation fails.

[MEDIUM - Google Play & Apple] Ephemeral Processing Disclosure
- Location: ios/FinanceFlow/PrivacyInfo.xcprivacy:L43-L44
- Recommendation: Declare Camera and Photo Library access in Google Play Data Safety
  as "Ephemeral Processing Only / Not Stored on Servers / Not Shared with Third Parties".

--------------------------------------------------------------------------------
2. BUGS THAT CAN CORRUPT OR INACCURATELY ALTER DATA
--------------------------------------------------------------------------------

[CRITICAL - Verified Data Corruption] Multi-Currency Transfer Reversal Error
- Location: app/(tabs)/transactions.js:L203-L205, app/(tabs)/index.js:L80-L82
- Issue: When deleting a multi-currency transfer (e.g. 100 USD to 92 EUR) and choosing
  "Yes, reverse transfer", it deducts transaction.amount (100) from the EUR account
  instead of the converted amount (92), permanently corrupting the destination balance.
- Fix: Convert the reversal delta into destination currency via convertCurrency().

[HIGH - Recurring Schedule Drift] Monthly Recurrence Day Rollover
- Location: utils/helpers.js:L183
- Issue: "d.setMonth(d.getMonth() + 1)" on Jan 31 rollovers to March 3 (skipping Feb).
  Future months permanently drift to the 3rd.
- Fix: Clamp day to Math.min(originalDay, daysInTargetMonth).

[HIGH - State Inconsistency] Stale In-Memory State on Account Deletion
- Location: context/AppContext.js:L99-L100, services/database.js:L399-L402
- Issue: SQLite clears assetId on transactions, but React Context reducer doesn't
  clear assetId in memory, leaving orphaned asset references until app restarts.
- Fix: Map state.transactions in DELETE_ASSET reducer to set assetId = null.

[HIGH - Foreign Key Orphan] Transfer Transactions Ignore Account Deletion
- Location: services/database.js:L399-L402
- Issue: deleteAsset() updates assetId, but ignores fromAssetId and toAssetId,
  leaving dangling account IDs in transfers.
- Fix: Add "UPDATE transactions SET fromAssetId = NULL WHERE fromAssetId = ?" and
  "UPDATE transactions SET toAssetId = NULL WHERE toAssetId = ?".

[MEDIUM - Timezone Skew] Custom Export Date Range Excludes Local Transactions
- Location: services/dataExport.js:L38-L39
- Issue: new Date(start + "T00:00:00Z") forces UTC. In UTC+8 local time, transactions
  between midnight and 8 AM on the start date are excluded.
- Fix: Parse using local date constructors.

--------------------------------------------------------------------------------
3. POTENTIAL CRASHES & STABILITY VULNERABILITIES
--------------------------------------------------------------------------------

[HIGH - Unhandled Null] Empty Array on Document Picker / Image Picker
- Location: app/pdf-statement-import.js:L196, app/receipt-scanner.js:L436
- Issue: Accessing result.assets[0].name throws TypeError if assets array is empty.
- Fix: Add guard: if (result.canceled || !result.assets?.length) return;

[HIGH - Native Process Termination] Metal GPU OOM Jetsam Kill on 4GB iOS Devices
- Location: services/localAI.js:L645-L647
- Issue: "n_gpu_layers: 99" on older iPhones (iPhone 11/12/13 with 4GB RAM) exhausts
  memory when loading 2B vision models, causing OS SIGKILL jetsam crash.
- Fix: Check Device.totalMemory and throttle n_gpu_layers to 24 on <= 4GB RAM.

[MEDIUM - Image Loading Failure] Percent Encoding in Native iOS CIImage Loader
- Location: modules/ReceiptOCR/ios/ReceiptOCRModule.swift:L70-L73
- Issue: URL(fileURLWithPath: clean) fails if path has %20 spaces.
- Fix: Use URL(string: uri) or removingPercentEncoding.

[MEDIUM - Form Input Reset] Prefill Hook Re-runs on Context Update
- Location: app/add-transaction.js:L205-L243
- Issue: useEffect([prefill, editId, assets]) overwrites form inputs if assets change.
- Fix: Use prefillAppliedRef to ensure prefill applies once.

const { withDangerousMod } = require('@expo/config-plugins');
const fs = require('fs');
const path = require('path');

const withMLKit = (config) => {
  return withDangerousMod(config, [
    'ios',
    async (config) => {
      const podfilePath = path.join(config.modRequest.platformProjectRoot, 'Podfile');
      let contents = fs.readFileSync(podfilePath, 'utf-8');

      // 1. Fix iOS deployment target for ML Kit
      contents = contents.replace(
        /platform :ios, podfile_properties\['ios.deploymentTarget'\] \|\| '.*'/,
        "platform :ios, '15.5'"
      );

      // 2. MLKit does not support arm64 simulator natively.
      // We must exclude arm64 on simulator and disable ONLY_ACTIVE_ARCH so Xcode builds for x86_64 (Rosetta).
      const patch = `
    # ── FIX MLKIT FOR APPLE SILICON SIMULATORS (ROSETTA) ──
    installer.pods_project.targets.each do |target|
      target.build_configurations.each do |config|
        config.build_settings["ARCHS[sdk=iphonesimulator*]"] = "x86_64"
        config.build_settings["VALID_ARCHS[sdk=iphonesimulator*]"] = "x86_64"
        config.build_settings["ONLY_ACTIVE_ARCH"] = "NO"
      end
    end
    main_project_path = File.join(__dir__, 'FinanceFlow.xcodeproj')
    main_project = Xcodeproj::Project.open(main_project_path)
    main_project.build_configurations.each do |config|
      config.build_settings["ARCHS[sdk=iphonesimulator*]"] = "x86_64"
      config.build_settings["VALID_ARCHS[sdk=iphonesimulator*]"] = "x86_64"
      config.build_settings["ONLY_ACTIVE_ARCH"] = "NO"
    end
    main_project.save
    # ────────────────────────────────────────────────────────
`;
      contents = contents.replace(/post_install do \|installer\|/, "post_install do |installer|\n" + patch);

      const postIntegratePatch = `
post_integrate do |installer|
  # Fix fmt consteval bug directly in source since it ignores compiler flags
  fmt_base_h = File.join(installer.sandbox.root, 'fmt/include/fmt/base.h')
  if File.exist?(fmt_base_h)
    fmt_text = File.read(fmt_base_h)
    fmt_new = fmt_text.gsub(/#  define FMT_USE_CONSTEVAL 1/, "#  define FMT_USE_CONSTEVAL 0")
    File.write(fmt_base_h, fmt_new)
  end
end
`;
      contents = contents + "\n" + postIntegratePatch;

      fs.writeFileSync(podfilePath, contents);
      return config;
    },
  ]);
};

module.exports = withMLKit;

const fs = require('fs');
const path = require('path');

const filePath = path.join(__dirname, '..', 'node_modules', 'react-native', 'React', 'Fabric', 'RCTSurfaceTouchHandler.mm');

if (fs.existsSync(filePath)) {
  let content = fs.readFileSync(filePath, 'utf8');
  const target = 'RCTAssert(iterator != _activeTouches.end(), @"Inconsistency between local and UIKit touch registries");';
  if (content.includes(target)) {
    content = content.split(target).join('// RCTAssert bypassed: guarded by if (iterator == _activeTouches.end()) continue; below');
    fs.writeFileSync(filePath, content, 'utf8');
    console.log('[patch-touch-handler] Successfully patched RCTSurfaceTouchHandler.mm');
  } else {
    console.log('[patch-touch-handler] RCTSurfaceTouchHandler.mm already patched or target not found.');
  }
} else {
  console.log('[patch-touch-handler] RCTSurfaceTouchHandler.mm does not exist (skip).');
}

function DatePickerModal({ visible, value, onConfirm, onClose, colors }) {
    const months = ['Jan', 'Feb', 'Mar', 'Apr', 'May', 'Jun', 'Jul', 'Aug', 'Sep', 'Oct', 'Nov', 'Dec'];
    const [month, setMonth] = useState(0);
    const [day, setDay] = useState(1);
    const [year, setYear] = useState(new Date().getFullYear());

    useEffect(() => {
        if (!visible) return;
        const date = value instanceof Date ? value : new Date(value);
        setMonth(date.getMonth());
        setDay(date.getDate());
        setYear(date.getFullYear());
    }, [visible, value]);

    const daysInMonth = new Date(year, month + 1, 0).getDate();

    const handleConfirm = () => {
        onConfirm(new Date(year, month, Math.min(day, daysInMonth)));
        onClose();
    };

    return (
        <Modal visible={visible} transparent animationType="fade">
            <View style={[styles.dpOverlay, { backgroundColor: colors.overlay }]}>
                <View style={[styles.dpBox, { backgroundColor: colors.modalBg }]}>
                    <Text style={[styles.dpTitle, { color: colors.textPrimary }]}>Select Date</Text>
                    <View style={styles.dpRow}>
                        {[
                            { label: 'Month', value: months[month], up: () => setMonth((month + 1) % 12), down: () => setMonth((month + 11) % 12) },
                            { label: 'Day', value: day, up: () => setDay(day >= daysInMonth ? 1 : day + 1), down: () => setDay(day <= 1 ? daysInMonth : day - 1) },
                            { label: 'Year', value: year, up: () => setYear(year + 1), down: () => setYear(year - 1) },
                        ].map((f, i) => (
                            <View key={i} style={styles.dpField}>
                                <Text style={styles.dpFieldLabel}>{f.label}</Text>
                                <TouchableOpacity onPress={f.up}><Ionicons name="chevron-up" size={22} color={colors.primary} /></TouchableOpacity>
                                <Text style={[styles.dpFieldValue, { color: colors.textPrimary }]}>{String(f.value).padStart(2, '0')}</Text>
                                <TouchableOpacity onPress={f.down}><Ionicons name="chevron-down" size={22} color={colors.primary} /></TouchableOpacity>
                            </View>
                        ))}
                    </View>
                    <View style={styles.dpBtnRow}>
                        <TouchableOpacity style={[styles.dpCancel, { backgroundColor: colors.primaryLight }]} onPress={onClose}>
                            <Text style={styles.dpCancelText}>Cancel</Text>
                        </TouchableOpacity>
                        <TouchableOpacity style={[styles.dpConfirm, { backgroundColor: colors.primary }]} onPress={handleConfirm}>
                            <Text style={styles.dpConfirmText}>Confirm</Text>
                        </TouchableOpacity>
                    </View>
                </View>
            </View>
        </Modal>
    );
}

            ) : (
                <View style={styles.dateNav}>
                    <TouchableOpacity style={[styles.navArrow, { backgroundColor: colors.primaryLight }]} onPress={() => navigate('prev')}>
                        <Ionicons name="chevron-back" size={18} color={colors.primary} />
                    </TouchableOpacity>
                    <TouchableOpacity style={[styles.dateLabelWrap, { backgroundColor: colors.card, borderColor: colors.border }]} onPress={() => setShowDateModal(true)}>
                        <Text style={[styles.dateLabel, { color: colors.textPrimary }]}>{periodLabel}</Text>
                        <Ionicons name="calendar-outline" size={14} color={colors.primary} />
                    </TouchableOpacity>
                    <TouchableOpacity style={[styles.navArrow, { backgroundColor: colors.primaryLight }]} onPress={() => navigate('next')}>
                        <Ionicons name="chevron-forward" size={18} color={colors.primary} />
                    </TouchableOpacity>
                </View>
            )}

            {/* Totals Card */}
            <View style={[styles.totalsCard, { backgroundColor: colors.card, borderColor: colors.border, shadowColor: isDark ? '#000' : '#1A1040' }]}>
                <TouchableOpacity style={styles.totalItem} onPress={() => setShowSummaryModal('income')} activeOpacity={0.7}>
                    <Text style={styles.totalAmountIncome}>+{formatCurrency(totalIncome, currency)}</Text>
                    <View style={{ flexDirection: 'row', alignItems: 'center', gap: 4 }}>
                        <Text style={styles.totalLabel}>Income</Text>
                        <Ionicons name="information-circle-outline" size={14} color={colors.textMuted} />
                    </View>
                </TouchableOpacity>
                <View style={styles.totalDivider} />
                <TouchableOpacity style={styles.totalItem} onPress={() => setShowSummaryModal('spending')} activeOpacity={0.7}>
                    <Text style={styles.totalAmountSpending}>-{formatCurrency(totalSpending, currency)}</Text>
                    <View style={{ flexDirection: 'row', alignItems: 'center', gap: 4 }}>
                        <Text style={styles.totalLabel}>Spending</Text>
                        <Ionicons name="information-circle-outline" size={14} color={colors.textMuted} />
                    </View>
                </TouchableOpacity>
            </View>

            {/* Search */}
            <View style={styles.searchRow}>
                <View style={[styles.searchBox, { backgroundColor: colors.card, borderColor: colors.border }]}>
                    <Ionicons name="search" size={16} color={colors.textSecondary} />
                    <TextInput
                        style={[styles.searchInput, { color: colors.textPrimary }]}
                        placeholder="Search transactions..."
                        placeholderTextColor={colors.textMuted}
                        value={search}
                        onChangeText={setSearch}
                    />
                    {search ? (
                        <TouchableOpacity onPress={() => setSearch('')}>
                            <Ionicons name="close-circle" size={16} color={colors.textSecondary} />
                        </TouchableOpacity>
                    ) : null}
                </View>
                <TouchableOpacity
                    style={[styles.filterToggle, { backgroundColor: showFilters || activeFilterCount > 0 ? colors.primaryLight : colors.card, borderColor: activeFilterCount > 0 ? colors.primary : colors.border }]}
                    onPress={() => setShowFilters(!showFilters)}
                >
                    <Ionicons name="options-outline" size={18} color={activeFilterCount > 0 ? colors.primary : colors.textSecondary} />
                    {activeFilterCount > 0 && (
                        <View style={[styles.filterBadge, { backgroundColor: colors.primary }]}>
                            <Text style={styles.filterBadgeText}>{activeFilterCount}</Text>
                        </View>
                    )}
                </TouchableOpacity>
            </View>

            {/* Advanced Filters Panel */}
            {showFilters && (
                <View style={[styles.filtersPanel, { backgroundColor: colors.card, borderColor: colors.border }]}>
                    {/* Type Filter */}
                    <View style={styles.filterSection}>
                        <Text style={[styles.filterSectionTitle, { color: colors.textSecondary }]}>Type</Text>
                        <View style={styles.filterChipRow}>
                            {[{ value: 'all', label: 'All' }, { value: 'income', label: 'Income' }, { value: 'spending', label: 'Spending' }, { value: 'move', label: 'Transfer' }].map(opt => (
                                <TouchableOpacity
                                    key={opt.value}
                                    style={[styles.filterChip, { backgroundColor: typeFilter === opt.value ? colors.primaryLight : colors.inputBg, borderColor: typeFilter === opt.value ? colors.primary : colors.border }]}
                                    onPress={() => setTypeFilter(opt.value)}
                                >
                                    <Text style={[styles.filterChipText, { color: typeFilter === opt.value ? colors.primary : colors.textSecondary }]}>{opt.label}</Text>
                                </TouchableOpacity>
                            ))}
                        </View>
                    </View>

                    {/* Category Filter */}
                    <View style={styles.filterSection}>
                        <Text style={[styles.filterSectionTitle, { color: colors.textSecondary }]}>Category</Text>
                        <ScrollView horizontal showsHorizontalScrollIndicator={false} contentContainerStyle={styles.filterChipRow}>
                            {allCategories.map(cat => {
                                const isSelected = categoryFilter.includes(cat.id);
                                return (
                                    <TouchableOpacity
                                        key={cat.id}
                                        style={[styles.filterChip, { backgroundColor: isSelected ? `${cat.color}20` : colors.inputBg, borderColor: isSelected ? cat.color : colors.border }]}
                                        onPress={() => setCategoryFilter(prev => isSelected ? prev.filter(c => c !== cat.id) : [...prev, cat.id])}
                                    >
                                        <Ionicons name={cat.icon} size={12} color={isSelected ? cat.color : colors.textMuted} />
                                        <Text style={[styles.filterChipText, { color: isSelected ? cat.color : colors.textSecondary }]}>{cat.name}</Text>
                                    </TouchableOpacity>
                                );
                            })}
                        </ScrollView>
                    </View>

                    {/* Amount Range */}
                    <View style={styles.filterSection}>
                        <Text style={[styles.filterSectionTitle, { color: colors.textSecondary }]}>Amount Range</Text>
                        <View style={styles.amountRangeRow}>
                            <TextInput
                                style={[styles.amountInput, { backgroundColor: colors.inputBg, borderColor: colors.border, color: colors.textPrimary }]}
                                placeholder="Min"
                                placeholderTextColor={colors.textMuted}
                                keyboardType="numeric"
                                value={amountMin}
                                onChangeText={setAmountMin}
                            />
                            <Text style={[{ color: colors.textMuted, fontFamily: 'Poppins_500Medium' }]}>—</Text>
                            <TextInput
                                style={[styles.amountInput, { backgroundColor: colors.inputBg, borderColor: colors.border, color: colors.textPrimary }]}
                                placeholder="Max"
                                placeholderTextColor={colors.textMuted}
                                keyboardType="numeric"
                                value={amountMax}
                                onChangeText={setAmountMax}
                            />
                        </View>
                    </View>



                    {/* Clear All */}
                    {activeFilterCount > 0 && (
                        <TouchableOpacity style={[styles.clearFiltersBtn, { backgroundColor: colors.redLight }]} onPress={clearAllFilters}>
                            <Ionicons name="close-circle-outline" size={14} color={colors.rose} />
                            <Text style={[styles.clearFiltersText, { color: colors.rose }]}>Clear All Filters</Text>
                        </TouchableOpacity>
                    )}
                </View>
            )}

            {/* Sort Chips */}
            <View style={styles.sortRow}>
                <Text style={[styles.sortLabel, { color: colors.textSecondary }]}>Sort:</Text>
                <ScrollView horizontal showsHorizontalScrollIndicator={false} contentContainerStyle={styles.sortChipRow}>
                    {sortOptions.map((option) => (
                        <TouchableOpacity
                            key={option.value}
                            style={[
                                styles.sortChip,
                                { backgroundColor: colors.card, borderColor: colors.border },
                                sortBy === option.value && [styles.sortChipActive, { backgroundColor: colors.primaryLight, borderColor: colors.primary }]
                            ]}
                            onPress={() => setSortBy(option.value)}
                        >
                            <Text style={[
                                styles.sortChipText,
                                { color: colors.textSecondary },
                                sortBy === option.value && [styles.sortChipTextActive, { color: colors.primary }]
                            ]}>
                                {option.label}
                            </Text>
                        </TouchableOpacity>
                    ))}
                </ScrollView>
            </View>

            {/* Transaction List */}
            {filtered.length === 0 ? (
                <View style={[styles.emptyState, { paddingBottom: 120, paddingHorizontal: Spacing.lg }]}>
                    <View style={[styles.emptyIconWrap, { backgroundColor: colors.primaryLight }]}>
                        <Ionicons name="receipt-outline" size={36} color={colors.primary} />
                    </View>
                    <Text style={[styles.emptyTitle, { color: colors.textPrimary }]}>No transactions</Text>
                    <Text style={[styles.emptyDesc, { color: colors.textSecondary }]}>No transactions found for this period</Text>
                </View>
            ) : (
                <FlatList
                    data={filtered}
                    keyExtractor={(item) => item.id}
                    showsVerticalScrollIndicator={false}
                    contentContainerStyle={{ paddingBottom: 120, paddingHorizontal: Spacing.lg }}
                    initialNumToRender={15}
                    maxToRenderPerBatch={10}
                    windowSize={5}
                    renderItem={({ item: transaction }) => {
                        const isMove = transaction.type === 'move';
                        let category = isMove
                            ? { name: 'Transfer', icon: 'swap-horizontal', color: '#6A6FF8' }
                            : getCategoryById(transaction.category);
                        if (transaction.vehicleLogType === 'refuel') category = { ...category, name: 'Car Refuel' };
                        if (transaction.vehicleLogType === 'maintenance') category = { ...category, name: 'Car Maintenance' };
                        const isIncome = transaction.type === 'income';
                        const expanded = expandedId === transaction.id;
                        const asset = transaction.assetId ? assets.find(a => a.id === transaction.assetId) : null;
                        const txOriginalCur = transaction.currency || currency;
                        const originalAmt = formatCurrency(Math.abs(transaction.amount), txOriginalCur);
                        const hasDiffCur = txOriginalCur !== currency;
                        const baseAmt = hasDiffCur ? formatCurrency(Math.abs(convertCurrency(transaction.amount, txOriginalCur, currency, exchangeRates)), currency) : null;

                        return (
                            <TouchableOpacity
                                style={[styles.txCard, { backgroundColor: colors.card }]}
                                onPress={() => setExpandedId(expanded ? null : transaction.id)}
                                activeOpacity={0.82}
                            >
                                <View style={styles.txMain}>
                                    <View style={[styles.txIcon, { backgroundColor: isDark ? `${category.color}33` : `${category.color}18` }]}>
                                        <Ionicons name={category.icon} size={20} color={category.color} />
                                    </View>
                                    <View style={styles.txInfo}>
                                        <Text style={[styles.txName, { color: colors.textPrimary }]} numberOfLines={1}>
                                            {transaction.description || category.name}
                                        </Text>
                                        <Text style={[styles.txMeta, { color: colors.textSecondary }]}>{category.name} · {formatTime(transaction.date)}</Text>

                                    </View>
                                    <View style={{ alignItems: 'flex-end' }}>
                                        <Text style={[styles.txAmount, {
                                            color: isMove ? colors.blue : isIncome ? colors.emerald : colors.rose
                                        }]}>
                                            {isMove ? '⇄ ' : isIncome ? '+' : '-'}{originalAmt}
                                        </Text>
                                        {hasDiffCur && (
                                            <Text style={{ fontSize: 11, color: colors.textMuted, marginTop: 2 }}>
                                                {baseAmt}
                                            </Text>
                                        )}
                                    </View>
                                </View>

                                {expanded && (
                                    <View style={styles.txExpanded}>
                                        <View style={[styles.txExpandedDivider, { backgroundColor: colors.border }]} />
                                        <Text style={[styles.txDetail, { color: colors.textSecondary }]}>📅 {formatDate(transaction.date)}</Text>
                                        {(isMove || (transaction.paymentMethod === 'asset' && asset)) && (
                                            <Text style={[styles.txDetail, { color: colors.textSecondary }]}>
                                                {isMove ? '💱 Transfer between accounts' : `💳 ${asset ? asset.name : 'Account'}`}
                                            </Text>
                                        )}
                                        {(transaction.items || []).length > 0 && (
                                            <View style={styles.txItems}>
                                                <Text style={[styles.txDetailLabel, { color: colors.textPrimary }]}>Items:</Text>
                                                {transaction.items.map((item, index) => (
                                                    <Text key={`${transaction.id}-${index}`} style={[styles.txDetail, { color: colors.textSecondary }]}>
                                                        · {item.name} ×{item.quantity || 1} = {formatCurrency((item.price || 0) * (item.quantity || 1), currency)}
                                                    </Text>
                                                ))}
                                            </View>
                                        )}


                                        <View style={styles.txActions}>
                                            <TouchableOpacity
                                                style={styles.editBtn}
                                                onPress={() => router.push({ pathname: '/add-transaction', params: { editId: transaction.id } })}
                                            >
                                                <Ionicons name="pencil" size={13} color="#6A6FF8" />
                                                <Text style={styles.editTxt}>Edit</Text>
                                            </TouchableOpacity>
                                            <TouchableOpacity style={styles.deleteBtn} onPress={() => confirmDelete(transaction)}>
                                                <Ionicons name="trash" size={13} color="#dc2626" />
                                                <Text style={styles.deleteTxt}>Delete</Text>
                                            </TouchableOpacity>
                                        </View>
                                    </View>
                                )}
                            </TouchableOpacity>
                        );
                    }}
                />
            )}

            <DatePickerModal
                visible={showDateModal}
                value={refDate}
                onConfirm={setRefDate}
                onClose={() => setShowDateModal(false)}
                colors={colors}
            />

            {/* Summary Breakdown Modal */}
            <Modal visible={!!showSummaryModal} transparent animationType="fade">
                <View style={styles.smOverlay}>
                    <View style={[styles.smBox, { backgroundColor: colors.card }]}>

                        {/* Header — matches vehicle modal */}
                        <View style={styles.smHeader}>
                            <View style={[styles.smIconWrap, {
                                backgroundColor: showSummaryModal === 'income' ? 'rgba(5,150,105,0.12)' : 'rgba(220,38,38,0.12)'
                            }]}>
                                <Ionicons
                                    name={showSummaryModal === 'income' ? 'trending-up' : 'trending-down'}
                                    size={20}
                                    color={showSummaryModal === 'income' ? colors.emerald : colors.rose}
                                />
                            </View>
                            <Text style={[styles.smTitle, { color: colors.textPrimary }]}>
                                {showSummaryModal === 'income' ? 'Income' : 'Spending'} Breakdown
                            </Text>
                            <TouchableOpacity
                                onPress={() => setShowSummaryModal(null)}
                                style={[styles.smClose, { backgroundColor: colors.inputBg }]}
                            >
                                <Ionicons name="close" size={18} color={colors.textSecondary} />
                            </TouchableOpacity>
                        </View>

                        {/* Per-currency rows */}
                        {summaryBreakdown.map((item) => (
                            <View key={item.cur} style={[styles.smRow, { borderColor: colors.border }]}>
                                {/* Currency badge */}
                                <View style={[styles.smCurBadge, { backgroundColor: colors.inputBg }]}>
                                    <Text style={[styles.smCurCode, { color: colors.textPrimary }]}>{item.cur}</Text>
                                </View>

                                {/* Amounts */}
                                <View style={styles.smAmounts}>
                                    <Text style={[styles.smOriginal, { color: colors.textPrimary }]}>
                                        {formatCurrency(item.originalTotal, item.cur)}
                                    </Text>
                                    {item.cur !== currency && (
                                        <View style={styles.smConvRow}>
                                            <Ionicons name="return-down-forward" size={13} color={colors.textMuted} />
                                            <Text style={[styles.smConverted, {
                                                color: showSummaryModal === 'income' ? colors.emerald : colors.rose
                                            }]}>
                                                {formatCurrency(item.convertedTotal, currency)}
                                            </Text>
                                        </View>
                                    )}
                                </View>
                            </View>
                        ))}

                        {/* Total row */}
                        <View style={[styles.smTotalRow, { borderTopColor: colors.border }]}>
                            <Text style={[styles.smTotalLabel, { color: colors.textSecondary }]}>Total in {currency}</Text>
                            <Text style={[styles.smTotalVal, {
                                color: showSummaryModal === 'income' ? colors.emerald : colors.rose
                            }]}>
                                {formatCurrency(summaryTotal, currency)}
                            </Text>
                        </View>

                        {/* Close button */}
                        <View style={styles.smActions}>
                            <TouchableOpacity
                                style={[styles.smDoneBtn, { backgroundColor: colors.primary }]}
                                onPress={() => setShowSummaryModal(null)}
                            >
                                <Text style={styles.smDoneTxt}>Done</Text>
                            </TouchableOpacity>
                        </View>

                    </View>
                </View>
            </Modal>
        </View>
    );
}

const getOrdinal = (n) => {
    const num = parseInt(n, 10) || 1;
    const s = ['th', 'st', 'nd', 'rd'];
    const v = num % 100;
    return num + (s[(v - 20) % 10] || s[v] || s[0]);
};

export default function Budget() {
    const { colors, isDark } = useTheme();
    const router = useRouter();
    const { budgets, transactions, currency, exchangeRates, addBudget, updateBudget, deleteBudget, currentDateKey } = useApp();
    const [showModal, setShowModal] = useState(false);
    const [editBudget, setEditBudget] = useState(null);
    const [period, setPeriod] = useState('monthly');
    const [cycleStartDay, setCycleStartDay] = useState(1);
    const [showDayPicker, setShowDayPicker] = useState(false);
    const [tempCycleDay, setTempCycleDay] = useState(1);

    const [amount, setAmount] = useState('');
    const { width: screenWidth, height: screenHeight } = useWindowDimensions();

        () => [{ id: 'all', name: 'All Spending', icon: 'wallet-outline', color: colors.primary }, ...spendingCategories],
        [colors.primary]
    );

    const budgetSnapshots = useMemo(
        () => budgets.map((budget) => ({
            budget,
            usage: calculateBudgetUsage(
                transactions,
                budget,
                new Date(currentDateKey),
                t => convertCurrency(t.amount || 0, t.currency || currency, currency, exchangeRates)
            )
        })),
        [budgets, transactions, currentDateKey, currency, exchangeRates]
    );

    const openAdd = () => {
        setEditBudget(null);
        setPeriod('monthly');
        setCycleStartDay(1);
        setTempCycleDay(1);
        setCategory('all');
        setAmount('');
        setShowModal(true);
    };

    const openEdit = (b) => {
        setEditBudget(b);
        setPeriod(b.period);
        setCycleStartDay(b.cycleStartDay || 1);
        setTempCycleDay(b.cycleStartDay || 1);
        setCategory(b.category || 'all');
        setAmount(b.amount.toString());

        const amt = parseFloat(amount);
        if (!amt || amt <= 0) {
            Alert.alert('Error', 'Please enter a valid amount');
            return;

        const budgetCategory = category || 'all';
        const startDay = period === 'monthly' ? (parseInt(cycleStartDay, 10) || 1) : 1;
        if (editBudget) {
            await updateBudget({ ...editBudget, period, category: budgetCategory, amount: amt, cycleStartDay: startDay });
        } else {
            const existingBudget = budgets.find(b => b.period === period && (b.category || 'all') === budgetCategory && (b.cycleStartDay || 1) === startDay);
            if (existingBudget) {

function DatePickerInput({ label, value, onChange, colors }) {
    const [show, setShow] = useState(false);
    const d = value ? new Date(value) : new Date();
    const [month, setMonth] = useState(d.getMonth());
    const [day, setDay] = useState(d.getDate());
    const [year, setYear] = useState(d.getFullYear());
    const monthNames = ['Jan', 'Feb', 'Mar', 'Apr', 'May', 'Jun', 'Jul', 'Aug', 'Sep', 'Oct', 'Nov', 'Dec'];

    const open = () => {
        const cur = value ? new Date(value) : new Date();
        setMonth(cur.getMonth()); setDay(cur.getDate()); setYear(cur.getFullYear());
        setShow(true);
    };
    const confirm = () => {
        const daysInM = new Date(year, month + 1, 0).getDate();
        const safeDay = Math.min(day, daysInM);
        const y = year;
        const m = String(month + 1).padStart(2, '0');
        const d = String(safeDay).padStart(2, '0');
        onChange(`${y}-${m}-${d}`);
        setShow(false);
    };
    const daysInMonth = new Date(year, month + 1, 0).getDate();

    return (
        <>
            <TouchableOpacity onPress={open} style={[styles.dateField, { backgroundColor: colors.inputBg, borderColor: colors.inputBorder }]}>
                <Ionicons name="calendar-outline" size={16} color={colors.primary} />
                <Text style={value ? [styles.dateFieldText, { color: colors.textPrimary }] : [styles.dateFieldPlaceholder, { color: colors.textMuted }]}>
                    {value ? formatDate(value) : `Select ${label}`}
                </Text>
            </TouchableOpacity>
            <Modal visible={show} transparent animationType="fade">
                <View style={[styles.dpOverlay, { backgroundColor: colors.overlay }]}>
                    <View style={[styles.dpBox, { backgroundColor: colors.modalBg }]}>
                        <Text style={[styles.dpTitle, { color: colors.textPrimary }]}>Select {label}</Text>
                        <View style={styles.dpRow}>
                            {[
                                { label: 'Month', value: monthNames[month], up: () => setMonth((month + 1) % 12), down: () => setMonth((month + 11) % 12) },
                                { label: 'Day', value: day, up: () => setDay(day >= daysInMonth ? 1 : day + 1), down: () => setDay(day <= 1 ? daysInMonth : day - 1) },
                                { label: 'Year', value: year, up: () => setYear(year + 1), down: () => setYear(year - 1) },
                            ].map((f, i) => (
                                <View key={i} style={styles.dpField}>
                                    <Text style={styles.dpFieldLabel}>{f.label}</Text>
                                    <TouchableOpacity onPress={f.up}><Ionicons name="chevron-up" size={22} color={colors.primary} /></TouchableOpacity>
                                    <Text style={[styles.dpFieldValue, { color: colors.textPrimary }]}>{String(f.value).padStart(2, '0')}</Text>
                                    <TouchableOpacity onPress={f.down}><Ionicons name="chevron-down" size={22} color={colors.primary} /></TouchableOpacity>
                                </View>
                            ))}
                        </View>
                        <View style={styles.dpBtnRow}>
                            <TouchableOpacity onPress={() => requestAnimationFrame(() => setShow(false))} style={[styles.dpCancel, { backgroundColor: colors.primaryLight }]}><Text style={styles.dpCancelText}>Cancel</Text></TouchableOpacity>
                            <TouchableOpacity onPress={confirm} style={[styles.dpConfirm, { backgroundColor: colors.primary }]}><Text style={styles.dpConfirmText}>Confirm</Text></TouchableOpacity>
                        </View>
                    </View>
                </View>
            </Modal>
        </>
    );
}

    };

    const handleDelete = (id) => {
        Alert.alert('Delete Goal', 'Are you sure you want to delete this goal?', [
            { text: 'Cancel', style: 'cancel' },
            {
                text: 'Delete',
                style: 'destructive',
                onPress: async () => {
                    await deleteSavingGoal(id);
                    await cancelGoalReminder(id);
                },
            },
        ]);
    };

    const active = savingsGoals.filter(g => !g.isCompleted);
    const completed = savingsGoals.filter(g => g.isCompleted);
    const totalSaved = savingsGoals.reduce((s, g) => s + (g.currentAmount || 0), 0);
    const totalTarget = savingsGoals.reduce((s, g) => s + (g.targetAmount || 0), 0);

    return (
        <View style={[styles.container, { backgroundColor: colors.background }]}>
            {/* Gradient background */}
            <Svg key={colors.background} style={StyleSheet.absoluteFillObject} width={screenWidth} height={screenHeight} pointerEvents="none">
                <Defs>
                    <SvgGrad id="bgGrad" x1="0.2" y1="0" x2="0.8" y2="1">
                        <Stop offset="0" stopColor={colors.gradientStart} stopOpacity="1" />
                        <Stop offset="0.5" stopColor={colors.gradientMid} stopOpacity="1" />
                        <Stop offset="1" stopColor={colors.gradientEnd} stopOpacity="1" />
                    </SvgGrad>
                </Defs>
                <Rect x="0" y="0" width={screenWidth} height={screenHeight} fill="url(#bgGrad)" />
            </Svg>

            {/* Header */}
            <View style={styles.header}>
                <View>
                    <Text style={[styles.title, { color: colors.textPrimary }]}>Saving Goals</Text>
                    {savingsGoals.length > 0 && (
                        <Text style={[styles.subtitle, { color: colors.textSecondary }]}>
                            {formatCurrency(totalSaved, currency)} of {formatCurrency(totalTarget, currency)} saved
                        </Text>
                    )}
                </View>
                <TouchableOpacity style={styles.addBtn} onPress={openAdd} activeOpacity={0.85}>
                    <Ionicons name="add" size={18} color="#fff" />
                    <Text style={styles.addBtnText}>New Goal</Text>
                </TouchableOpacity>
            </View>

            <ScrollView showsVerticalScrollIndicator={false} contentContainerStyle={styles.scrollContent}>
                {active.length === 0 && completed.length === 0 ? (
                    <View style={styles.emptyState}>
                        <View style={[styles.emptyIconWrap, { backgroundColor: colors.primaryLight }]}>
                            <Ionicons name="flag-outline" size={40} color={colors.primary} />
                        </View>
                        <Text style={[styles.emptyTitle, { color: colors.textPrimary }]}>No saving goals yet</Text>
                        <Text style={[styles.emptyDesc, { color: colors.textSecondary }]}>Set a goal and start saving towards it</Text>
                        <TouchableOpacity style={[styles.emptyAddBtn, { backgroundColor: colors.primary }]} onPress={openAdd} activeOpacity={0.85}>
                            <Ionicons name="add" size={16} color="#fff" />
                            <Text style={styles.emptyAddBtnText}>Create Your First Goal</Text>
                        </TouchableOpacity>
                    </View>
                ) : null}

                {active.map(goal => {
                    const pct = goal.targetAmount > 0 ? Math.min((goal.currentAmount / goal.targetAmount) * 100, 100) : 0;
                    const remaining = goal.targetAmount - goal.currentAmount;
                    const barColor = pct >= 100 ? '#059669' : pct > 60 ? '#F59E0B' : colors.primary;
                    return (
                        <View key={goal.id} style={[styles.goalCard, { backgroundColor: colors.card, shadowColor: isDark ? '#000' : '#1A1040' }]}>
                            <View style={styles.goalCardInner}>
                                <View style={styles.goalHeader}>
                                    <TouchableOpacity
                                        style={styles.goalTitleRow}
                                        onPress={() => setDetailGoalId(goal.id)}
                                        activeOpacity={0.85}
                                    >
                                        <View style={[styles.goalFlagWrap, { backgroundColor: isDark ? `${barColor}33` : `${barColor}18` }]}>
                                            <Ionicons name="flag" size={14} color={barColor} />
                                        </View>
                                        <Text style={[styles.goalTitle, { color: colors.textPrimary }]} numberOfLines={1}>{goal.title}</Text>
                                    </TouchableOpacity>
                                    <View style={styles.goalActions}>
                                        <TouchableOpacity onPress={() => openEdit(goal)} style={[styles.iconBtn, { backgroundColor: colors.inputBg }]} accessibilityLabel="Edit Goal">
                                            <Ionicons name="pencil" size={15} color={colors.textSecondary} />
                                        </TouchableOpacity>
                                        <TouchableOpacity onPress={() => handleDelete(goal.id)} style={[styles.iconBtn, { backgroundColor: colors.inputBg }]} accessibilityLabel="Delete Goal">
                                            <Ionicons name="trash" size={15} color={colors.rose} />
                                        </TouchableOpacity>
                                    </View>
                                </View>

                                <TouchableOpacity activeOpacity={0.88} onPress={() => setDetailGoalId(goal.id)} accessibilityLabel="Goal Details">
                                    <View style={styles.amountRow}>
                                        <Text style={[styles.currentAmt, { color: barColor }]}>{formatCurrency(goal.currentAmount || 0, currency)}</Text>
                                        <Text style={[styles.targetAmt, { color: colors.textMuted }]}> / {formatCurrency(goal.targetAmount, currency)}</Text>
                                    </View>

                                    {/* Progress */}
                                    <View style={styles.progressBarWrap}>
                                        <View style={[styles.progressBar, { backgroundColor: colors.border }]}>
                                            <View style={[styles.progressFill, { width: `${pct}%`, backgroundColor: barColor }]} />
                                        </View>
                                        <Text style={[styles.pctBadge, { color: barColor }]}>{pct.toFixed(0)}%</Text>
                                    </View>

                                    {remaining > 0 && (
                                        <Text style={[styles.remainText, { color: colors.textSecondary }]}>{formatCurrency(remaining, currency)} remaining</Text>
                                    )}

                                    {(goal.startDate || goal.endDate) && (
                                        <View style={styles.dateRow}>
                                            <Ionicons name="calendar-outline" size={12} color={colors.textSecondary} />
                                            <Text style={[styles.dateMeta, { color: colors.textSecondary }]}>
                                                {goal.startDate ? formatDate(goal.startDate) : '?'}
                                                {' → '}
                                                {goal.endDate ? formatDate(goal.endDate) : '?'}
                                            </Text>
                                        </View>
                                    )}

                                    {goal.commitment && (
                                        <View style={[styles.commitBadge, { backgroundColor: isDark ? 'rgba(245,158,11,0.2)' : 'rgba(245,158,11,0.1)' }]}>
                                            <Ionicons name="notifications" size={11} color="#F59E0B" />
                                            <Text style={styles.commitText}>
                                                {goal.commitment.charAt(0).toUpperCase() + goal.commitment.slice(1)} commitment
                                                {goal.notifyEnabled ? ' · Reminders on' : ''}
                                            </Text>
                                        </View>
                                    )}
                                </TouchableOpacity>

                                <View style={styles.goalBtnRow}>
                                    <TouchableOpacity
                                        accessibilityRole="button"
                                        accessibilityLabel={`Add Savings ${goal.title}`}
                                        style={[styles.addSavingBtn, { backgroundColor: barColor }]}
                                        onPress={() => { setAddTarget(goal); setAddAmount(''); setShowAddModal(true); }}
                                        activeOpacity={0.85}
                                    >
                                        <Ionicons name="add" size={16} color="#fff" />
                                        <Text style={styles.addSavingBtnText}>Add Savings</Text>
                                    </TouchableOpacity>
                                    <TouchableOpacity style={[styles.completeBtn, { borderColor: barColor }]} onPress={() => handleComplete(goal)} activeOpacity={0.85}>
                                        <Ionicons name="checkmark-circle-outline" size={15} color={barColor} />
                                        <Text style={[styles.completeBtnText, { color: barColor }]}>Complete</Text>
                                    </TouchableOpacity>
                                </View>
                                <Text style={styles.historyHint}>Tap card to view goal details and add-savings history</Text>
                            </View>
                        </View>
                    );
                })}

                {completed.length > 0 && (
                    <>
                        <View style={styles.sectionHeader}>
                            <Ionicons name="checkmark-circle" size={16} color={colors.emerald} />
                            <Text style={[styles.sectionTitle, { color: colors.emerald }]}>Completed Goals</Text>
                        </View>
                        {completed.map(goal => (
                            <TouchableOpacity key={goal.id} style={[styles.goalCard, styles.goalCardCompleted, { backgroundColor: colors.card }]} onPress={() => setDetailGoalId(goal.id)} activeOpacity={0.95}>
                                <View style={styles.goalCardInner}>
                                    <View style={styles.goalHeader}>
                                        <View style={styles.goalTitleRow}>
                                            <View style={[styles.goalFlagWrap, { backgroundColor: isDark ? `${colors.emerald}33` : `${colors.emerald}18` }]}>
                                                <Ionicons name="checkmark-circle" size={14} color={colors.emerald} />
                                            </View>
                                            <Text style={[styles.goalTitle, { color: colors.textSecondary }]}>{goal.title}</Text>
                                        </View>
                                        <TouchableOpacity onPress={() => handleDelete(goal.id)} style={[styles.iconBtn, { backgroundColor: colors.inputBg }]}>
                                            <Ionicons name="trash" size={15} color={colors.rose} />
                                        </TouchableOpacity>
                                    </View>
                                    <Text style={styles.completedTag}>
                                        🎉 {formatCurrency(goal.currentAmount || 0, currency)} / {formatCurrency(goal.targetAmount, currency)} · Goal achieved!
                                    </Text>
                                    <Text style={styles.historyHint}>Tap card to view goal details and add-savings history</Text>
                                </View>
                            </TouchableOpacity>
                        ))}
                    </>
                )}

                <View style={{ height: 120 }} />
            </ScrollView>

            {/* Add/Edit Goal Modal */}
            <Modal visible={showModal} animationType="slide" transparent onRequestClose={() => { setShowModal(false); setEditGoal(null); }}>
                <View style={[styles.modalOverlay, { backgroundColor: colors.overlay }]}>
                    <ScrollView contentContainerStyle={styles.modalScroll}>
                        <View style={[styles.modalBox, { backgroundColor: colors.modalBg }]}>
                            <View style={styles.modalHandle} />
                            <View style={styles.modalHeader}>
                                <Text style={[styles.modalTitle, { color: colors.textPrimary }]}>{editGoal ? 'Edit Goal' : 'New Saving Goal'}</Text>
                                <TouchableOpacity onPress={() => requestAnimationFrame(() => setShowModal(false))} style={[styles.closeBtn, { backgroundColor: colors.inputBg }]}>
                                    <Ionicons name="close" size={20} color={colors.textSecondary} />
                                </TouchableOpacity>
                            </View>

                            <Text style={[styles.inputLabel, { color: colors.textSecondary }]}>What is this saving for?</Text>
                            <FastInput
                                style={[styles.input, { color: colors.textPrimary, backgroundColor: colors.inputBg, borderColor: colors.inputBorder }]}
                                placeholder="e.g. Buy a new PC"
                                placeholderTextColor={colors.textMuted}
                                value={title}
                                onChangeText={setTitle}
                            />

                            <Text style={[styles.inputLabel, { color: colors.textSecondary }]}>Target Amount ({currency})</Text>
                            <FastInput
                                style={[styles.input, { color: colors.textPrimary, backgroundColor: colors.inputBg, borderColor: colors.inputBorder }]}
                                placeholder="0"
                                placeholderTextColor={colors.textMuted}
                                value={targetAmount}
                                onChangeText={setTargetAmount}
                                keyboardType="numeric"
                            />

                            <View style={{ flexDirection: 'row', gap: Spacing.sm }}>
                                <View style={{ flex: 1 }}>
                                    <Text style={[styles.inputLabel, { color: colors.textSecondary }]}>Start Date</Text>
                                    <DatePickerInput label="Start Date" value={startDate} onChange={setStartDate} colors={colors} />
                                </View>
                                <View style={{ flex: 1 }}>
                                    <Text style={[styles.inputLabel, { color: colors.textSecondary }]}>End Date</Text>
                                    <DatePickerInput label="End Date" value={endDate} onChange={setEndDate} colors={colors} />
                                </View>
                            </View>

                            <View style={[styles.commitBox, { backgroundColor: colors.inputBg, borderColor: colors.border }]}>
                                <TouchableOpacity style={styles.checkRow} onPress={() => setNotifyEnabled(!notifyEnabled)}>
                                    <View style={[styles.checkbox, { borderColor: colors.border }, notifyEnabled && [styles.checkboxChecked, { backgroundColor: colors.primary, borderColor: colors.primary }]]}>
                                        {notifyEnabled && <Ionicons name="checkmark" size={12} color="#fff" />}
                                    </View>
                                    <Text style={[styles.checkLabel, { color: colors.textSecondary }]}>Enable regular saving reminders</Text>
                                </TouchableOpacity>
                                {notifyEnabled && (
                                    <>
                                        <View style={styles.periodRow}>
                                            {['daily', 'weekly', 'monthly'].map(p => (
                                                <TouchableOpacity
                                                    key={p}
                                                    style={[styles.periodChip, { backgroundColor: colors.card, borderColor: colors.border }, commitment === p && [styles.periodChipActive, { backgroundColor: colors.primaryLight, borderColor: colors.primary }]]}
                                                    onPress={() => setCommitment(p)}
                                                >
                                                    <Text style={[styles.periodChipText, { color: colors.textMuted }, commitment === p && [styles.periodChipTextActive, { color: colors.primary }]]}>
                                                        {p.charAt(0).toUpperCase() + p.slice(1)}
                                                    </Text>
                                                </TouchableOpacity>
                                            ))}
                                        </View>
                                        {/* Per-goal reminder time row */}
                                        <TouchableOpacity
                                            style={{ flexDirection: 'row', alignItems: 'center', justifyContent: 'space-between', marginTop: 10, paddingVertical: 8, paddingHorizontal: 10, borderRadius: 10, backgroundColor: colors.card }}
                                            onPress={() => { setPickerHour(reminderHour); setPickerMinute(reminderMinute); setShowTimePicker(true); }}
                                            activeOpacity={0.8}
                                        >
                                            <View style={{ flexDirection: 'row', alignItems: 'center', gap: 6 }}>
                                                <Ionicons name="alarm-outline" size={14} color={colors.primary} />
                                                <Text style={{ fontSize: FontSize.xs, color: colors.textMuted, fontFamily: 'Poppins_400Regular' }}>Reminder time</Text>
                                            </View>
                                            <View style={{ flexDirection: 'row', alignItems: 'center', gap: 6 }}>
                                                <Text style={{ fontSize: FontSize.sm, fontFamily: 'Poppins_700Bold', color: colors.primary }}>
                                                    {formatTime(reminderHour, reminderMinute)}
                                                </Text>
                                                <Ionicons name="chevron-forward" size={14} color={colors.primary} />
                                            </View>
                                        </TouchableOpacity>
                                    </>
                                )}
                            </View>

                            {notifyEnabled && commitment && startDate && endDate && (
                                <View style={[styles.planHintBox, { backgroundColor: isDark ? 'rgba(16,185,129,0.15)' : 'rgba(16,185,129,0.08)' }]}>
                                    <Ionicons name="information-circle" size={15} color={colors.emerald} />
                                    <Text style={[styles.planHintText, { color: colors.emerald }]}>
                                        {savingPlan
                                            ? `You will reach your goal by saving ${formatCurrency(savingPlan.amountPerPeriod, currency)} ${planningCommitmentLabel}.`
                                            : 'End date must be later than start date to calculate your required saving amount.'}
                                    </Text>
                                </View>
                            )}

                            <TouchableOpacity style={[styles.saveBtn, { backgroundColor: colors.primary, shadowColor: colors.primary }]} onPress={handleSave} activeOpacity={0.85}>
                                <Text style={styles.saveBtnText}>{editGoal ? 'Update Goal' : 'Create Goal'}</Text>
                            </TouchableOpacity>
                        </View>
                    </ScrollView>
                    {/* Per-goal reminder time picker OVERLAY */}
                    {showTimePicker && (
                        <View style={[StyleSheet.absoluteFill, { zIndex: 1000, backgroundColor: colors.overlay, justifyContent: 'center', alignItems: 'center' }]}>
                            <View style={{ backgroundColor: colors.modalBg, borderRadius: 22, padding: Spacing.xl, width: '85%', maxWidth: 360, shadowColor: '#000', shadowOpacity: 0.25, shadowRadius: 10, elevation: 5 }}>
                                <Text style={{ fontSize: FontSize.lg, fontFamily: 'Poppins_700Bold', color: colors.textPrimary, marginBottom: Spacing.lg, textAlign: 'center' }}>
                                    Reminder Time
                                </Text>
                                <View style={{ flexDirection: 'row', justifyContent: 'center', gap: Spacing.xl, marginBottom: Spacing.lg }}>
                                    {/* Hour */}
                                    <View style={{ alignItems: 'center', gap: Spacing.sm }}>
                                        <Text style={{ fontSize: FontSize.xs, color: colors.textMuted, fontFamily: 'Poppins_500Medium' }}>HOUR</Text>
                                        <TouchableOpacity onPress={() => setPickerHour(h => h <= 0 ? 23 : h - 1)}>
                                            <Ionicons name="chevron-up" size={26} color={colors.primary} />
                                        </TouchableOpacity>
                                        <Text style={{ fontSize: 36, fontFamily: 'Poppins_700Bold', color: colors.textPrimary, minWidth: 56, textAlign: 'center' }}>
                                            {pickerHour === 0 ? 12 : pickerHour > 12 ? pickerHour - 12 : pickerHour}
                                        </Text>
                                        <TouchableOpacity onPress={() => setPickerHour(h => h >= 23 ? 0 : h + 1)}>
                                            <Ionicons name="chevron-down" size={26} color={colors.primary} />
                                        </TouchableOpacity>
                                    </View>
                                    <Text style={{ fontSize: 36, fontFamily: 'Poppins_700Bold', color: colors.textPrimary, marginTop: 28 }}>:</Text>
                                    {/* Minute */}
                                    <View style={{ alignItems: 'center', gap: Spacing.sm }}>
                                        <Text style={{ fontSize: FontSize.xs, color: colors.textMuted, fontFamily: 'Poppins_500Medium' }}>MIN</Text>
                                        <TouchableOpacity onPress={() => setPickerMinute(m => m <= 0 ? 55 : m - 5)}>
                                            <Ionicons name="chevron-up" size={26} color={colors.primary} />
                                        </TouchableOpacity>
                                        <Text style={{ fontSize: 36, fontFamily: 'Poppins_700Bold', color: colors.textPrimary, minWidth: 56, textAlign: 'center' }}>
                                            {String(pickerMinute).padStart(2, '0')}
                                        </Text>
                                        <TouchableOpacity onPress={() => setPickerMinute(m => m >= 55 ? 0 : m + 5)}>
                                            <Ionicons name="chevron-down" size={26} color={colors.primary} />
                                        </TouchableOpacity>
                                    </View>
                                    {/* AM/PM */}
                                    <View style={{ alignItems: 'center', gap: Spacing.sm, justifyContent: 'center', marginTop: 10 }}>
                                        <TouchableOpacity
                                            onPress={() => setPickerHour(h => h < 12 ? h : h - 12)}
                                            style={{ paddingHorizontal: 12, paddingVertical: 8, borderRadius: 10, backgroundColor: pickerHour < 12 ? colors.primary : colors.inputBg }}
                                        >
                                            <Text style={{ fontFamily: 'Poppins_700Bold', fontSize: FontSize.sm, color: pickerHour < 12 ? '#fff' : colors.textMuted }}>AM</Text>
                                        </TouchableOpacity>
                                        <TouchableOpacity
                                            onPress={() => setPickerHour(h => h >= 12 ? h : h + 12)}
                                            style={{ paddingHorizontal: 12, paddingVertical: 8, borderRadius: 10, backgroundColor: pickerHour >= 12 ? colors.primary : colors.inputBg }}
                                        >
                                            <Text style={{ fontFamily: 'Poppins_700Bold', fontSize: FontSize.sm, color: pickerHour >= 12 ? '#fff' : colors.textMuted }}>PM</Text>
                                        </TouchableOpacity>
                                    </View>
                                </View>
                                <View style={{ flexDirection: 'row', gap: Spacing.sm }}>
                                    <TouchableOpacity
                                        style={{ flex: 1, padding: Spacing.md, borderRadius: BorderRadius.md, borderWidth: 1, borderColor: colors.border, alignItems: 'center' }}
                                        onPress={() => requestAnimationFrame(() => setShowTimePicker(false))}
                                    >
                                        <Text style={{ fontFamily: 'Poppins_600SemiBold', fontSize: FontSize.sm, color: colors.textSecondary }}>Cancel</Text>
                                    </TouchableOpacity>
                                    <TouchableOpacity
                                        style={{ flex: 1, padding: Spacing.md, borderRadius: BorderRadius.md, backgroundColor: colors.primary, alignItems: 'center' }}
                                        onPress={() => { setReminderHour(pickerHour); setReminderMinute(pickerMinute); setShowTimePicker(false); }}
                                    >
                                        <Text style={{ fontFamily: 'Poppins_700Bold', fontSize: FontSize.sm, color: '#fff' }}>Set Time</Text>
                                    </TouchableOpacity>
                                </View>
                            </View>
                        </View>
                    )}
                </View>
            </Modal>


            {/* Add to Saving Modal */}
            <Modal visible={showAddModal} animationType="fade" transparent onRequestClose={() => setShowAddModal(false)}>
                <View style={[styles.modalOverlay, { backgroundColor: colors.overlay }]}>
                    <View style={[styles.modalBox, { margin: Spacing.xl, backgroundColor: colors.modalBg }]}>
                        <View style={styles.modalHandle} />
                        <View style={styles.modalHeader}>
                            <Text style={[styles.modalTitle, { color: colors.textPrimary }]}>Add to Saving</Text>
                            <TouchableOpacity onPress={() => requestAnimationFrame(() => setShowAddModal(false))} style={[styles.closeBtn, { backgroundColor: colors.inputBg }]}>
                                <Ionicons name="close" size={20} color={colors.textSecondary} />
                            </TouchableOpacity>
                        </View>
                        {addTarget && (
                            <Text style={[styles.addTargetName, { color: colors.textSecondary }]}>🎯 {addTarget.title}</Text>
                        )}
                        {addTargetPlan && (
                            <View style={[styles.planHintBox, { backgroundColor: colors.primaryLight }]}>
                                <Ionicons name="trending-up-outline" size={15} color={colors.primary} />
                                <Text style={[styles.planHintText, { color: colors.primary }]}>
                                    Stay on track by adding around {formatCurrency(addTargetPlan.amountPerPeriod, currency)} {addTargetPlan.commitment}.
                                </Text>
                            </View>
                        )}
                        <Text style={[styles.inputLabel, { color: colors.textSecondary }]}>Amount ({currency})</Text>
                        <FastInput
                            style={[styles.input, { fontSize: FontSize.xxxl, fontFamily: 'Poppins_800ExtraBold', textAlign: 'center', color: colors.textPrimary, backgroundColor: colors.inputBg, borderColor: colors.inputBorder }]}
                            placeholder="0"
                            placeholderTextColor={colors.textMuted}
                            value={addAmount}
                            onChangeText={setAddAmount}
                            keyboardType="numeric"
                            autoFocus
                        />
                        <TouchableOpacity style={styles.saveBtn} onPress={handleAddToSaving} activeOpacity={0.85}>
                            <Ionicons name="add-circle" size={18} color="#fff" />
                            <Text style={styles.saveBtnText}>Add to Saving</Text>
                        </TouchableOpacity>
                    </View>
                </View>
            </Modal>

            {/* Goal Detail + Saving History Modal */}
            <Modal visible={!!detailGoal} animationType="slide" transparent onRequestClose={() => setDetailGoalId(null)}>
                <View style={[styles.modalOverlay, { backgroundColor: colors.overlay }]}>
                    <ScrollView contentContainerStyle={styles.modalScroll}>
                        <View style={[styles.modalBox, { backgroundColor: colors.modalBg }]}>
                            <View style={styles.modalHandle} />
                            <View style={styles.modalHeader}>
                                <Text style={[styles.modalTitle, { color: colors.textPrimary }]}>Goal Details</Text>
                                <TouchableOpacity onPress={() => requestAnimationFrame(() => setDetailGoalId(null))} style={[styles.closeBtn, { backgroundColor: colors.inputBg }]}>
                                    <Ionicons name="close" size={20} color={colors.textSecondary} />
                                </TouchableOpacity>
                            </View>

                            {detailGoal && (
                                <>
                                    <Text style={[styles.detailTitle, { color: colors.textPrimary }]}>{detailGoal.title}</Text>
                                    <Text style={[styles.detailAmount, { color: colors.textSecondary }]}>
                                        {formatCurrency(detailGoal.currentAmount || 0, currency)} / {formatCurrency(detailGoal.targetAmount || 0, currency)}
                                    </Text>
                                    <Text style={[styles.detailMeta, { color: colors.textSecondary }]}>
                                        {detailGoal.startDate ? formatDate(detailGoal.startDate) : '?'} {' → '} {detailGoal.endDate ? formatDate(detailGoal.endDate) : '?'}
                                    </Text>
                                    {detailGoal.notifyEnabled && detailGoal.commitment ? (
                                        <Text style={[styles.detailMeta, { color: colors.textSecondary }]}>Reminder: {detailGoal.commitment}</Text>
                                    ) : null}

                                    <TouchableOpacity
                                        accessibilityRole="button"
                                        accessibilityLabel="Add Savings From Details"
                                        style={[styles.saveBtn, { marginVertical: Spacing.md }]}
                                        onPress={() => {
                                            const g = detailGoal;
                                            setDetailGoalId(null);
                                            setTimeout(() => {
                                                setAddTarget(g);
                                                setAddAmount('');
                                                setShowAddModal(true);
                                            }, 250);
                                        }}
                                        activeOpacity={0.85}
                                    >
                                        <Ionicons name="add-circle" size={18} color="#fff" />
                                        <Text style={styles.saveBtnText}>+ Add Savings to this Goal</Text>
                                    </TouchableOpacity>

                                    <View style={styles.historyHeaderRow}>
                                        <Text style={[styles.historyHeader, { color: colors.textPrimary }]}>Add Savings History</Text>
                                    </View>

                                    {normalizeSavingHistory(detailGoal).length === 0 ? (
                                        <Text style={[styles.noHistoryText, { color: colors.textSecondary }]}>No savings added yet.</Text>
                                    ) : (
                                        [...normalizeSavingHistory(detailGoal)]
                                            .sort((a, b) => new Date(b.date || b.createdAt) - new Date(a.date || a.createdAt))
                                            .map(entry => (
                                                <View key={entry.id || `${entry.date}-${entry.amount}`} style={[styles.historyRow, { borderBottomColor: colors.border }]}>
                                                    <View style={styles.historyRowLeft}>
                                                        <Ionicons name="arrow-up-circle" size={16} color={colors.emerald} />
                                                        <Text style={[styles.historyAmount, { color: colors.emerald }]}>+{formatCurrency(entry.amount || 0, currency)}</Text>

function DatePickerModal({ visible, value, onConfirm, onClose, colors }) {
    const months = ['Jan', 'Feb', 'Mar', 'Apr', 'May', 'Jun', 'Jul', 'Aug', 'Sep', 'Oct', 'Nov', 'Dec'];
    const [month, setMonth] = useState(0);
    const [day, setDay] = useState(1);
    const [year, setYear] = useState(new Date().getFullYear());

    useEffect(() => {
        if (!visible) return;
        const date = value instanceof Date ? value : new Date(value);
        setMonth(date.getMonth());
        setDay(date.getDate());
        setYear(date.getFullYear());
    }, [visible, value]);

    const daysInMonth = new Date(year, month + 1, 0).getDate();

    const handleConfirm = () => {
        onConfirm(new Date(year, month, Math.min(day, daysInMonth)));
        onClose();
    };

    return (
        <Modal visible={visible} transparent animationType="fade">
            <View style={[styles.dpOverlay, { backgroundColor: colors.overlay }]}>
                <View style={[styles.dpBox, { backgroundColor: colors.modalBg }]}>
                    <Text style={[styles.dpTitle, { color: colors.textPrimary }]}>Select Date</Text>
                    <View style={styles.dpRow}>
                        {[
                            { label: 'Month', value: months[month], up: () => setMonth((month + 1) % 12), down: () => setMonth((month + 11) % 12) },
                            { label: 'Day', value: day, up: () => setDay(day >= daysInMonth ? 1 : day + 1), down: () => setDay(day <= 1 ? daysInMonth : day - 1) },
                            { label: 'Year', value: year, up: () => setYear(year + 1), down: () => setYear(year - 1) },
                        ].map((f, i) => (
                            <View key={i} style={styles.dpField}>
                                <Text style={styles.dpFieldLabel}>{f.label}</Text>
                                <TouchableOpacity onPress={f.up}><Ionicons name="chevron-up" size={22} color={colors.primary} /></TouchableOpacity>
                                <Text style={[styles.dpFieldValue, { color: colors.textPrimary }]}>{String(f.value).padStart(2, '0')}</Text>
                                <TouchableOpacity onPress={f.down}><Ionicons name="chevron-down" size={22} color={colors.primary} /></TouchableOpacity>
                            </View>
                        ))}
                    </View>
                    <View style={styles.dpBtnRow}>
                        <TouchableOpacity style={[styles.dpCancel, { backgroundColor: colors.primaryLight }]} onPress={onClose}>
                            <Text style={styles.dpCancelText}>Cancel</Text>
                        </TouchableOpacity>
                        <TouchableOpacity style={[styles.dpConfirm, { backgroundColor: colors.primary }]} onPress={handleConfirm}>
                            <Text style={styles.dpConfirmText}>Confirm</Text>
                        </TouchableOpacity>
                    </View>
                </View>
            </View>
        </Modal>
    );
}

                            <View style={styles.trendBars}>
                                <View style={styles.trendBarPair}>
                                    <View style={[styles.trendBar, { height: incomeHeight, backgroundColor: colors.emerald }]} />
                                    <View style={[styles.trendBar, { height: spendingHeight, backgroundColor: colors.rose }]} />
                                </View>
                            </View>
                            <Text style={[styles.trendLabel, { color: colors.textSecondary }]}>{item.label}</Text>
                        </View>
                    );
                })}
            </View>
            <View style={[styles.trendTotalRow, { borderColor: colors.border }]}>
                <Text style={[styles.trendTotalText, { color: colors.textSecondary }]}>
                    6-month spending
                </Text>
                <Text style={[styles.trendTotalAmount, { color: colors.rose }]}>
                    {formatCurrency(data.reduce((sum, item) => sum + item.spending, 0), currency)}
                </Text>
            </View>
        </View>
    );
}

function AssetsTrendChart({ data, colors, currency, width }) {
    const chartHeight = 120;
    const paddingX = 10;
    const paddingY = 15;
    
    const chartWidth = width - 68; // available width inside card
    
    const values = data.map(item => item.value);
    let maxVal = Math.max(...values, 100);
    let minVal = Math.min(...values, 0);

    if (values.length > 0) {
        const actualMax = Math.max(...values);
        const actualMin = Math.min(...values);
        if (actualMax === actualMin) {
            maxVal = actualMax + (Math.abs(actualMax) * 0.1 || 10);
            minVal = actualMin - (Math.abs(actualMin) * 0.1 || 10);
        } else {
            const padding = (actualMax - actualMin) * 0.15; // 15% padding
            maxVal = actualMax + padding;
            minVal = actualMin - padding;
        }
    }
    const range = maxVal - minVal;

    const points = data.map((item, idx) => {
        const x = paddingX + (idx * (chartWidth - 2 * paddingX)) / 5;
        const y = chartHeight - paddingY - ((item.value - minVal) / (range || 1)) * (chartHeight - 2 * paddingY);
        return { x, y, label: item.label, value: item.value };
    });

    const [selectedIndex, setSelectedIndex] = useState(points.length - 1);
    
    React.useEffect(() => {
        setSelectedIndex(points.length - 1);
    }, [points.length]);

    const pathD = points.map((p, idx) => `${idx === 0 ? 'M' : 'L'} ${p.x} ${p.y}`).join(' ');
    const areaD = points.length > 0
        ? `${pathD} L ${points[points.length - 1].x} ${chartHeight} L ${points[0].x} ${chartHeight} Z`
        : '';

    return (
        <View style={styles.assetsChartWrap}>
            <View style={{ height: chartHeight, width: chartWidth }}>
                <Svg width={chartWidth} height={chartHeight}>
                    <Defs>
                        <SvgGrad id="lineGrad" x1="0" y1="0" x2="1" y2="0">
                            <Stop offset="0" stopColor={colors.primary} />
                            <Stop offset="1" stopColor="#F59E0B" />
                        </SvgGrad>
                        <SvgGrad id="areaGrad" x1="0" y1="0" x2="0" y2="1">
                            <Stop offset="0" stopColor={colors.primary} stopOpacity="0.28" />
                            <Stop offset="1" stopColor={colors.primary} stopOpacity="0.00" />
                        </SvgGrad>
                    </Defs>
                    {/* Area under the line */}
                    {areaD ? <Path d={areaD} fill="url(#areaGrad)" /> : null}
                    
                    {/* Line stroke */}
                    {pathD ? <Path d={pathD} fill="none" stroke="url(#lineGrad)" strokeWidth={3} /> : null}
                    
                    {/* Selected vertical indicator line */}
                    {points.map((p, idx) => {
                        if (idx !== selectedIndex) return null;
                        return (
                            <Line
                                key={`line-${idx}`}
                                x1={p.x}
                                y1={paddingY}
                                x2={p.x}
                                y2={chartHeight - paddingY}
                                stroke={colors.primary}
                                strokeDasharray="3 3"
                                strokeWidth={1.5}
                                opacity={0.6}
                            />
                        );
                    })}
                    
                    {/* Data point circles */}
                    {points.map((p, idx) => {
                        const isSelected = idx === selectedIndex;
                        return (
                            <Circle
                                key={idx}
                                cx={p.x}
                                cy={p.y}
                                r={isSelected ? 6 : 4}
                                fill={isSelected ? colors.primary : "#FFFFFF"}
                                stroke={colors.primary}
                                strokeWidth={2}
                            />
                        );
                    })}

                    {/* Touch targets */}
                    {points.map((p, idx) => (
                        <Circle
                            key={`touch-${idx}`}
                            cx={p.x}
                            cy={p.y}
                            r={24}
                            fill="transparent"
                            onPress={() => setSelectedIndex(idx)}
                        />
                    ))}
                </Svg>
            </View>
            {/* X-axis Labels */}
            <View style={[styles.assetsChartLabels, { width: chartWidth }]}>
                {points.map((p, idx) => {
                    const isSelected = idx === selectedIndex;
                    return (
                        <TouchableOpacity key={idx} onPress={() => setSelectedIndex(idx)}>
                            <Text style={[
                                styles.assetsChartLabelText, 
                                { color: colors.textSecondary },
                                isSelected && { color: colors.primary, fontFamily: 'Poppins_700Bold' }
                            ]}>
                                {p.label}
                            </Text>
                        </TouchableOpacity>
                    );
                })}
            </View>
            {/* Selected balance info row */}
            <View style={[styles.trendTotalRow, { borderColor: colors.border, marginTop: Spacing.sm }]}>
                <Text style={[styles.trendTotalText, { color: colors.textSecondary }]}>
                    Assets balance in {points[selectedIndex]?.label}
                </Text>
                <Text style={[styles.trendTotalAmount, { color: colors.primary }]}>
                    {formatCurrency(points[selectedIndex]?.value || 0, currency)}
                </Text>
            </View>
        </View>
    );
}

export default function Charts() {
    const router = useRouter();
    const { colors, isDark } = useTheme();
    const { transactions, currency, currentDateKey, assets, exchangeRates, convertCurrency } = useApp();
    const [period, setPeriod] = useState('monthly');
    const [refDate, setRefDate] = useState(new Date());
    const [showDateModal, setShowDateModal] = useState(false);
    const { width: screenWidth, height: screenHeight } = useWindowDimensions();

    const navigate = (direction) => {
        if (period === 'all') return;
        const fn = direction === 'next'
            ? (period === 'daily' ? addDays : period === 'weekly' ? addWeeks : addMonths)
            : (period === 'daily' ? subDays : period === 'weekly' ? subWeeks : subMonths);
        setRefDate(fn(refDate, 1));
    };

    const periodTx = useMemo(
        () => filterTransactionsByPeriod(transactions, period, refDate),
        [transactions, period, refDate]
    );
    const monthlyTrend = useMemo(() => {
        const referenceDate = new Date(currentDateKey);
        return Array.from({ length: 6 }, (_, index) => {
            const monthDate = new Date(referenceDate.getFullYear(), referenceDate.getMonth() - (5 - index), 1);
            const month = monthDate.getMonth();
            const year = monthDate.getFullYear();
            const monthTransactions = transactions.filter(transaction => {
                const transactionDate = new Date(transaction.date);
                return transactionDate.getFullYear() === year && transactionDate.getMonth() === month;
            });
            return {
                key: `${year}-${month}`,
                label: monthDate.toLocaleString('en-US', { month: 'short' }),
                income: monthTransactions
                    .filter(transaction => transaction.type === 'income')
                    .reduce((sum, transaction) => sum + Math.abs(convertCurrency(transaction.amount, transaction.currency || currency, currency, exchangeRates)), 0),
                spending: monthTransactions
                    .filter(transaction => transaction.type === 'spending')
                    .reduce((sum, transaction) => sum + Math.abs(convertCurrency(transaction.amount, transaction.currency || currency, currency, exchangeRates)), 0),
            };
        });
    }, [transactions, currentDateKey, currency, exchangeRates]);

    const assetsTrend = useMemo(() => {
        const referenceDate = new Date(currentDateKey);
        
        const currentBalances = {};
        (assets || []).forEach(a => {
            currentBalances[a.id] = a.balance || 0;
        });

        const sortedTx = [...transactions].sort((a, b) => new Date(b.date) - new Date(a.date));

        const monthlyBalances = [];
        let txIndex = 0;

        for (let i = 5; i >= 0; i--) {
            const monthDate = new Date(referenceDate.getFullYear(), referenceDate.getMonth() - (5 - i), 1);
            const endOfMonth = new Date(monthDate.getFullYear(), monthDate.getMonth() + 1, 0, 23, 59, 59, 999);

            while (txIndex < sortedTx.length) {
                const tx = sortedTx[txIndex];
                const txDate = new Date(tx.date);
                if (txDate <= endOfMonth) {
                    break;
                }
                
                const rawAmount = Math.abs(tx.amount || 0);
                if (tx.type === 'income' && tx.assetId && currentBalances[tx.assetId] !== undefined) {
                    const asset = (assets || []).find(a => a.id === tx.assetId);
                    const assetCur = asset?.currency || currency;
                    const amount = convertCurrency(rawAmount, tx.currency || assetCur, assetCur, exchangeRates);
                    currentBalances[tx.assetId] -= amount;
                } else if (tx.type === 'spending' && tx.assetId && currentBalances[tx.assetId] !== undefined) {
                    const asset = (assets || []).find(a => a.id === tx.assetId);
                    const assetCur = asset?.currency || currency;
                    const amount = convertCurrency(rawAmount, tx.currency || assetCur, assetCur, exchangeRates);
                    currentBalances[tx.assetId] += amount;
                } else if (tx.type === 'move') {
                    if (tx.fromAssetId && currentBalances[tx.fromAssetId] !== undefined) {
                        const fromAsset = (assets || []).find(a => a.id === tx.fromAssetId);
                        const fromCur = fromAsset?.currency || tx.currency || currency;
                        const amount = convertCurrency(rawAmount, tx.currency || fromCur, fromCur, exchangeRates);
                        currentBalances[tx.fromAssetId] += amount;
                    }
                    if (tx.toAssetId && currentBalances[tx.toAssetId] !== undefined) {
                        const toAsset = (assets || []).find(a => a.id === tx.toAssetId);
                        const toCur = toAsset?.currency || currency;
                        const fromCur = (assets || []).find(a => a.id === tx.fromAssetId)?.currency || tx.currency || currency;
                        const destAmount = convertCurrency(rawAmount, fromCur, toCur, exchangeRates);
                        currentBalances[tx.toAssetId] -= destAmount;
                    }
                }
                txIndex++;
            }

            let totalVal = 0;
            (assets || []).forEach(a => {
                const assetCreatedAt = new Date(a.createdAt || new Date().toISOString());
                // Only include this asset's balance if it was created before or during this month
                if (assetCreatedAt <= endOfMonth) {
                    totalVal += convertCurrency(currentBalances[a.id] || 0, a.currency || currency, currency, exchangeRates);
                }
            });
            
            monthlyBalances[i] = {
                key: `${monthDate.getFullYear()}-${monthDate.getMonth()}`,
                label: monthDate.toLocaleString('en-US', { month: 'short' }),
                value: totalVal,
            };
        }
        
        return monthlyBalances;
    }, [transactions, assets, currentDateKey, currency, exchangeRates]);

    const spendingTx = periodTx.filter(t => t.type === 'spending');
    const incomeTx = periodTx.filter(t => t.type === 'income');

                <Defs>
                    <SvgGrad id="bgGrad" x1="0.2" y1="0" x2="0.8" y2="1">
                        <Stop offset="0" stopColor={colors.gradientStart} stopOpacity="1" />
                        <Stop offset="0.5" stopColor={colors.gradientMid} stopOpacity="1" />
                        <Stop offset="1" stopColor={colors.gradientEnd} stopOpacity="1" />
                    </SvgGrad>

            {/* Header */}

package com.financeflow.app

import android.appwidget.AppWidgetManager
import android.content.ComponentName
import android.content.Context
import android.content.Intent
import com.facebook.react.bridge.Promise
import com.facebook.react.bridge.ReactApplicationContext
import com.facebook.react.bridge.ReactContextBaseJavaModule
import com.facebook.react.bridge.ReactMethod

class WidgetDataModule(reactContext: ReactApplicationContext) :
    ReactContextBaseJavaModule(reactContext) {

    override fun getName(): String = "WidgetDataModule"

    @ReactMethod
    fun updateWidgetData(jsonData: String, promise: Promise) {
        try {
            val context = reactApplicationContext

            // Persist to SharedPreferences
            val prefs = context.getSharedPreferences(
                DailyAllowanceWidget.PREFS_NAME,
                Context.MODE_PRIVATE
            )
            prefs.edit().putString(DailyAllowanceWidget.KEY_DATA, jsonData).apply()

            // Notify all Daily Allowance widgets to refresh
            val manager = AppWidgetManager.getInstance(context)
            val dailyIds = manager.getAppWidgetIds(
                ComponentName(context, DailyAllowanceWidget::class.java)
            )
            if (dailyIds.isNotEmpty()) {
                val intent = Intent(context, DailyAllowanceWidget::class.java).apply {
                    action = AppWidgetManager.ACTION_APPWIDGET_UPDATE
                    putExtra(AppWidgetManager.EXTRA_APPWIDGET_IDS, dailyIds)
                }
                context.sendBroadcast(intent)
            }

            // Notify Quick Actions widgets to refresh
            val quickIds = manager.getAppWidgetIds(
                ComponentName(context, QuickActionsWidget::class.java)
            )
            if (quickIds.isNotEmpty()) {
                val intent = Intent(context, QuickActionsWidget::class.java).apply {
                    action = AppWidgetManager.ACTION_APPWIDGET_UPDATE
                    putExtra(AppWidgetManager.EXTRA_APPWIDGET_IDS, quickIds)
                }
                context.sendBroadcast(intent)
            }

            promise.resolve(null)
        } catch (e: Exception) {
            promise.reject("WIDGET_UPDATE_ERROR", e.message, e)
        }
    }
}
